# Документация проекта UEBA-RS-1.0

Эксплуатационная документация и документация сопровождения модуля расчёта Risk Score для подсистемы обнаружения аномалий в поведении пользователей (лабораторная работа № 4). Документы хранятся в формате Markdown (подход Documentation as Code).

## Состав

- docs/operator-guide.md — руководство оператора (ГОСТ 19.505-79);
- docs/admin-guide.md — руководство администратора (по аналогии с ГОСТ 19.503-79);
- docs/architecture.md — описание архитектуры системы;
- docs/database.md — описание структуры базы данных;
- docs/maintenance.md — порядок актуализации документации;
- docs/api.md — описание программного интерфейса (бонус);
- docs/diagrams/ — диаграммы (исходный текст PlantUML и изображения);
- CHANGELOG.md — журнал изменений.

Текущая версия комплекта указана в CHANGELOG.md.
