# Руководство оператора

**Обозначение:** UEBA-RS.РО.01

**Программа:** Модуль расчёта Risk Score для подсистемы обнаружения аномалий в поведении пользователей (UEBA-RS-1.0)

**Основание:** ГОСТ 19.505-79 «ЕСПД. Руководство оператора»; структура — раздел 3.1 учебного пособия.

## 1. Назначение программы

### 1.1 Назначение документа

Настоящее руководство предназначено для операторов системы UEBA-RS-1.0 — сотрудников центра мониторинга информационной безопасности (SOC-аналитиков). Документ описывает, как открыть рабочее место, прочитать результаты расчёта Risk Score, выполнить расчёт по требованию и выгрузить данные, а также как действовать при появлении сообщений системы.

### 1.2 Назначение и функции программы

Модуль UEBA-RS-1.0 автоматически рассчитывает комплексный показатель риска (Risk Score, от 0 до 100) для каждого объекта мониторинга — учётной записи пользователя или хоста. Показатель строится как взвешенная сумма двух нормализованных оценок: аномальности поведения (алгоритм Isolation Forest) и центральности объекта в графе связей (библиотека NetworkX).

Оператору доступны следующие функции:

- просмотр сводки по уровням риска (низкий, средний, высокий, критический);
- просмотр рейтинга объектов, отсортированного по убыванию Risk Score;
- просмотр карточки объекта с динамикой показателя;
- расчёт Risk Score по требованию (для аналитиков уровня L2/L3);
- выгрузка результатов в форматах CSV и JSON.

### 1.3 Категории операторов и права доступа

Таблица – Роли оператора и разрешённые действия

| Роль | Разрешённые действия | Ограничения |
|---|---|---|
| SOC-аналитик L1 | Просмотр сводки, рейтинга и карточек объектов; выгрузка результатов | Не может запускать расчёт по требованию и менять параметры |
| SOC-аналитик L2/L3 | Все действия L1; расчёт по требованию; временное изменение весов в рамках одного расчёта | Не может менять постоянную конфигурацию (это делает администратор) |

Для работы оператор должен знать основы информационной безопасности и уметь работать с веб-приложениями. Для аналитиков L2/L3 дополнительно требуется понимание смысла показателей аномальности и центральности.

## 2. Условия выполнения программы

### 2.1 Требования к рабочему месту оператора

Таблица – Требования к рабочему месту

| Параметр | Требование |
|---|---|
| Компьютер | Любой ПК с доступом к корпоративной сети |
| Монитор | Разрешение не менее 1920×1080 |
| Браузер | Актуальные версии Chrome, Firefox или Edge |
| Сетевой доступ | Доступ к адресу веб-интерфейса по HTTPS |
| Учётная запись | Корпоративная учётная запись, включённая в группу доступа к UEBA-RS |

Установка программы на рабочее место оператора не требуется: работа выполняется через веб-интерфейс (дашборд Streamlit).

### 2.2 Подключение и вход в систему

1. Откройте браузер и перейдите по адресу веб-интерфейса, сообщённому администратором (например, https://ueba-rs.corp.local).
2. При запросе авторизации введите корпоративный логин и пароль.
3. Дождитесь загрузки главной страницы. В правом верхнем углу отображаются ваше имя и роль.
4. Проверьте на странице «Сводка» время последнего расчёта: оно не должно быть старше двух часов.

### 2.3 Настройка рабочего места

- Установите масштаб страницы 100 %, чтобы все столбцы рейтинга помещались на экране.
- Включите часовой пояс, совпадающий с часовым поясом смены, — время в карточках объектов отображается в локальном времени.
- Не отключайте цвета в браузере: уровни риска различаются цветовой индикацией (дублируются текстом).

## 4. Выполнение программы

### 4.1 Просмотр сводки по смене

На странице «Сводка» отображаются четыре счётчика (по числу объектов в каждом уровне риска), диаграмма распределения Risk Score и список объектов с критическим уровнем. Данные обновляются автоматически после каждого пакетного расчёта (раз в час). Для принудительного обновления страницы нажмите клавишу F5.

### 4.2 Работа с рейтингом объектов

1. Откройте страницу «Рейтинг объектов».
2. При необходимости задайте фильтры на боковой панели: тип объекта (пользователь или хост), уровень риска, часть идентификатора.
3. Для сортировки нажмите на заголовок столбца. По умолчанию таблица отсортирована по убыванию Risk Score.
4. Для перехода к подробностям нажмите на идентификатор объекта.

### 4.3 Просмотр карточки объекта

Карточка объекта содержит идентификатор и тип объекта, текущий Risk Score и уровень риска, значения аномальности и центральности (исходные и нормализованные), график изменения Risk Score за последние 24 часа и использованные веса. Если за последние сутки показатель вырос более чем на 25 пунктов, рядом с ним выводится отметка «Резкий рост».

### 4.4 Расчёт Risk Score по требованию

Функция доступна только аналитикам L2/L3.

1. Откройте страницу «Расчёт по требованию».
2. Выберите объект из списка или введите его идентификатор.
3. При необходимости измените веса: сумма веса аномальности и веса центральности должна быть равна 1,0. Изменения действуют только для текущего расчёта и в конфигурации не сохраняются.
4. Нажмите «Рассчитать».
5. Дождитесь результата (обычно не более нескольких секунд) и проверьте значение и уровень риска в карточке объекта.

Примечание. Нормализация Min-Max зависит от распределения значений во всей выборке, поэтому расчёт выполняется для всех активных объектов, а на экран выводится результат по выбранному объекту.

### 4.5 Выгрузка результатов

1. На странице «Рейтинг объектов» отфильтруйте нужные объекты.
2. Нажмите «Скачать CSV» или «Скачать JSON».
3. Сохраните файл в разрешённое хранилище. Файлы содержат идентификаторы учётных записей и относятся к информации ограниченного доступа.

### 4.6 Завершение работы

Нажмите «Выйти» на боковой панели и закройте вкладку браузера. При бездействии более 30 минут сеанс завершается автоматически.

## 5. Типичные сценарии использования

### 5.1 Сценарий 1. Обход в начале смены

1. Войдите в систему и откройте страницу «Сводка».
2. Убедитесь, что последний расчёт выполнен не более двух часов назад.
3. Просмотрите список объектов с критическим уровнем риска.
4. Для каждого объекта откройте карточку и зафиксируйте решение (расследовать, эскалировать, закрыть) в системе учёта инцидентов.

### 5.2 Сценарий 2. Расследование критического объекта

1. В рейтинге выберите объект с Risk Score не ниже 75 и откройте его карточку.
2. Определите, что дало основной вклад: аномальность (необычное поведение) или центральность (важность узла в сети).
3. Если высокий показатель вызван центральностью при низкой аномальности, объект, скорее всего, важен, но ведёт себя штатно — приоритет ниже.
4. Если высока аномальность, передайте информацию аналитику L2/L3 для расследования.

### 5.3 Сценарий 3. Проверка гипотезы с другими весами

1. Аналитик L2/L3 открывает страницу «Расчёт по требованию» и выбирает объект.
2. Задаёт веса 0,8 и 0,2 (больший акцент на аномальности).
3. Сравнивает полученный показатель с показателем по умолчанию (0,6 и 0,4).
4. Если вывод изменился, передаёт администратору предложение пересмотреть веса в конфигурации.

## 6. Сообщения оператору

Таблица – Сообщения, выдаваемые оператору

| Сообщение | Причина | Действия оператора |
|---|---|---|
| Нет данных для отображения | Пакетный расчёт ещё не выполнялся или фильтры слишком строгие | Сбросить фильтры; если данных по-прежнему нет — сообщить администратору |
| Данные устарели: последний расчёт выполнен более 2 часов назад | Пакетный расчёт не выполнялся по расписанию | Сообщить администратору, до устранения использовать данные с осторожностью |
| Ошибка расчёта: длины массивов не совпадают | Модули аномальности и центральности передали разное число объектов | Сообщить администратору, не повторять расчёт до устранения причины |
| Ошибка расчёта: сумма весов должна быть равна 1.0 | Введены некорректные веса | Скорректировать веса так, чтобы их сумма равнялась 1,0, и повторить расчёт |
| Недостаточно данных для нормализации | В выборке меньше двух различных значений | Расширить выборку или сообщить администратору |
| Предупреждение: индексы входных массивов не совпадают | Идентификаторы объектов в данных аномальности и центральности различаются | Результат использовать с осторожностью, сообщить администратору для проверки выгрузки |
| Недостаточно прав для выполнения операции | Роль оператора не допускает операцию | Обратиться к администратору для изменения группы доступа |
| Не удалось отправить уведомление в SIEM | Недоступна SIEM-система | Результат расчёта сохранён; сообщить администратору, критические объекты обработать вручную |
| Сеанс завершён по тайм-ауту | Бездействие более 30 минут | Выполнить вход повторно |
